# Motion assets

Four hand-built SVGs. Two were generated by script (the maths would be
miserable by hand), two written directly. All four animate **inside the file**
using CSS and SMIL, so they keep working when loaded through `<img>` — where
scripts do not run — and cost nothing to place.

Every one honours `prefers-reduced-motion` internally as well as via
`style.css`, because a file loaded through `<img>` doesn't inherit the page's
media queries.

### `topo-summit.svg` — thirteen breathing contour rings

The brand mark is a summit inside a ring. This is the same idea drawn as a
topographic map: thirteen closed contours, each perturbed by four summed sine
harmonics so no ring repeats another, breathing on staggered negative delays so
the field drifts rather than pulsing in unison. The whole group rotates once
every four minutes — slow enough that you notice it only if you stop and look.

Regenerate with `GenTopo.ps1` (see below) to change ring count, wobble or size.

### `hex-drift.svg` — honeycomb lattice

The hexagonal mesh from the profile deck cover, rebuilt as a static asset for
the pages and sections that have no hero canvas. Roughly a third of the 132
cells glow on staggered offsets, chosen by a seeded pseudo-random sequence so
the shimmer looks irregular but the file regenerates identically every time.

### `mark-orbit.svg` — the mark, with a light travelling the ring

A spark runs the gold arc on an eight-second loop via SMIL `animateMotion`,
fading in and out at the ends of the path so it doesn't jump. The green peak
pulses slowly against it. Used large and at 7% opacity as a footer watermark.

### `grain.svg` — film grain tile

A 200px `feTurbulence` tile, desaturated, with `stitchTiles="stitch"` so it
repeats seamlessly. Laid over the page at ~5% opacity and jittered by a
`steps()` transform animation. Two reasons it earns its place: it stops the
large flat greens banding on cheap phone panels, and it reads as print texture
rather than as an effect — which suits a studio that does a lot of print.

## Regenerating

The two generated files came from PowerShell scripts using nothing but .NET —
no Node, no design tool. The scripts are not committed; recreate them from the
descriptions above if the artwork needs to change, or edit the SVGs directly
(they're plain text and the paths are readable).

If you regenerate, keep the coordinate precision at one decimal place. It is
invisible on screen and cuts the file size by roughly a third.

## Adding another

Place it here, reference it with `<img class="deco deco--yourname">` inside a
section carrying `.has-deco`, and add the positioning rule to the **MOTION
LAYER** block in `assets/css/style.css`. `.has-deco` handles the stacking and
clipping; `.deco` handles pointer-events and z-index. Anything decorative must
also carry `alt="" aria-hidden="true"` so screen readers skip it.
